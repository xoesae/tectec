# TecTec
## Install / update

Installs the latest release in `~/.local` (no root). Run it again to update.

```bash
curl -fsSL https://raw.githubusercontent.com/xoesae/tectec/main/packaging/install.sh | bash
```

From an extracted release archive, `./install.sh` does the same, and
`./install.sh --local` installs the files beside it instead (offline).
