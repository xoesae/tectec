# Icons

[Lucide](https://lucide.dev) icons from `lucide-static` 1.48.0 (ISC, see
`LICENSE.txt`), with the stroke set to white so egui's tint colours them, the
same format as fastframe's shared icons.

Icons are listed once, in `src/icons.rs`. To add one, drop its SVG here (or
name one of fastframe's shared icons with `lucide "name"`) and add a variant.
